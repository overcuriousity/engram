Browser extension

Capture what you are reading without reaching for the paste box, and search from a panel beside the page.

Firefox

{% if xpi_signed %}

Install — one click. This build carries an AMO-signed package.

{% else %}

Download the .xpi. It is unsigned, and Firefox will not install an unsigned add-on permanently, so there are three ways to run it — in the order most people should try them:

  1. Load it temporarily. Open about:debugging#/runtime/this-firefox, press Load Temporary Add-on, and pick the .xpi. It works immediately and is gone when Firefox restarts.
  2. Turn the signature check off. In about:config, set xpinstall.signatures.required to false, then open the file. This only works on Developer Edition, Nightly and ESR — release Firefox ignores the setting.
  3. Have it signed. An unlisted submission at addons.mozilla.org returns a signed file that installs in one click and stays. It is a build step rather than an install one — see extension/README.md.
{% endif %}

There is no auto-update. Come back here after a deployment.

Chrome

Download, unzip it, open chrome://extensions, turn on Developer mode, and press Load unpacked.

Chrome has no one-click path for an add-on from outside its store, and no auto-update.

On a phone

On Android, install engram from the browser’s menu and it joins the system share sheet by itself — share from any app, and it lands here. Nothing below is needed for that.

Safari has no share-target support, so on iOS the same gesture is reached through a bookmarklet, or through the Shortcuts app. Both carry a token minted for one device and revocable on its own under Settings → API tokens.

Pairing

Open the panel and enter the address you reach engram at — most likely {{ origin }}, though a deployment behind a proxy can answer to more than one, and the one your browser uses is the one to type. Press Pair: Firefox or Chrome will ask for permission to reach that one host, and nothing else.

The token appears under Settings → API tokens as “browser extension”, and can be revoked there. Revoking it puts the panel back to asking for an address rather than leaving it stuck.
