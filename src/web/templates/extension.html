Firefox

{% if xpi_signed %}

Install — one click. This build carries an AMO-signed package.

{% else %}

Download the .xpi. It is unsigned, and Firefox will not install an unsigned add-on permanently, so there are three ways to run it — in the order most people should try them:

  1. Load it temporarily. Open about:debugging#/runtime/this-firefox, press Load Temporary Add-on, and pick the .xpi. It works immediately and is gone when Firefox restarts.
  2. Turn the signature check off. In about:config, set xpinstall.signatures.required to false, then open the file. This only works on Developer Edition, Nightly and ESR — release Firefox ignores the setting.
  3. Have it signed. An add-on can be signed without being published: an unlisted submission at addons.mozilla.org is not reviewed, not listed and not searchable, and the signed file it returns installs in one click and stays. It needs a (free) Mozilla account. The steps are in extension/README.md; drop the result at extension/firefox-signed.xpi, rebuild, and this page will offer that instead.
{% endif %}

There is no auto-update: one artifact serves every deployment, and a manifest naming a single update host could not do that. Come back here after a deployment.

Chrome

Download, unzip it, open chrome://extensions, turn on Developer mode, and press Load unpacked.

Chrome blocks off-store installs for ordinary users, so there is no one-click path and no auto-update. An enterprise policy allowlist is the alternative, and is not the default here.

On a phone

On Android, install engram from the browser’s menu and it joins the system share sheet by itself — share from any app, and it lands here. Nothing below is needed for that.

Safari has no share-target support, so on iOS the same gesture is reached through a bookmarklet, or through the Shortcuts app. Both carry a token minted for one device and revocable on its own under Settings → API tokens.

The bookmarklet. Save this as a bookmark — drag it to the bar on a desktop, or add the page to favourites on the phone and edit the address to this. Pressing it captures the selection, or the page’s address when nothing is selected.

Capture to engram

The Shortcut. In the Shortcuts app: new shortcut, turn on Show in Share Sheet, accept text, URLs and images, then add one Get Contents of URL action with these:

URL
{{ origin }}/api/v1/capture
Method
POST
Header
Authorization: Bearer {{ token }}
Header
Content-Type: text/plain
Request Body
Shortcut Input

The four lines above are copied once, into Shortcuts. There is no importable file here on purpose: an unsigned .shortcut is a binary plist this server would have to fabricate, and one that imports wrongly is worse than four fields typed correctly.

Pairing

Open the panel and enter the address you reach engram at — most likely {{ origin }}, though a deployment behind a proxy can answer to more than one, and the one your browser uses is the one to type. Press Pair: Firefox or Chrome will ask for permission to reach that one host, and nothing else.

The token appears under Settings → API tokens as “browser extension”, and can be revoked there. Revoking it puts the panel back to asking for an address rather than leaving it stuck.
