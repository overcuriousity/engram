# Reap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A periodic `Reap` sweep that judges long-retired artifacts, wipes the worthless into a `graveyard` table, and rewrites the still-valuable as live `Synthesized` artifacts — no operator involvement.

**Architecture:** One new collection-targeted sweep stage following the `Consolidate`/`Retention` pattern (armed via `periodic_units`, accounted via `run_accounted`, backoff via `rearm_periodic`). Free SQL rules nominate candidates; one model call per candidate (the `core.judge` completer, as dedupe uses) returns `worthless` or `valuable`; the write paths reuse the existing lifecycle machinery (`lifecycle_lock`, `lifecycle_dirty`, `insert_synthesized_artifact`).

**Tech Stack:** Rust, sqlx/SQLite, Qdrant via the `VectorStore` trait, tokio. Tests use the house pattern: `test_core()` (fake embedder), `ScriptedCompleter` from `src/infer/fake.rs`.

**Spec:** `docs/superpowers/specs/2026-08-30-reap-design.md`

## Global Constraints

- Branch: all commits go on `feat/time`.
- Commit style: repo uses `feat(reap): ...` / `docs(reap): ...` lowercase subjects; end commit bodies with the Co-Authored-By/Claude-Session trailer the session uses elsewhere.

### Task 4: Rules pass — nominate, stamp, protect fresh merges

**Files:**
- Modify: `src/jobs/reap.rs`
- Test: same module

**Interfaces:**
- Consumes: `store.stamp_unaged_retired()`, `store.reap_candidates(min_age_secs, limit)`, `vectors.payloads_of(&ids)` (returns `HashMap<String, VectorPayload>`; `VectorPayload.last_seen_at: Option<i64>`), `Chunk.retired_at`.
- Produces: `async fn nominees(core: &Core) -> Result<(Vec<Chunk>, u64)>` — `(candidates, stamped)`, private to the module; `run` calls it first.

Rules applied here, in order, each dropping rows:

1. `stamp_unaged_retired` runs first; its count is `Report.stamped`.
2. `reap_candidates` does age + status + open-moment in SQL, fetching `max_judged_per_run` rows.
3. Seen-since-retirement: fetch `payloads_of` for the batch; drop any candidate whose payload `last_seen_at` is `Some(t)` with `t >= retired_at`. A candidate with *no* point (never embedded, or already cleaned) passes — unseen by definition.
4. Fresh-merge protection: drop a candidate that is a source of an active merge younger than `min_age_days`. SQL (add to `src/store/artifacts.rs` as `pub async fn sources_of_fresh_merges(&self, min_age_secs: i64) -> Result<Vec<String>>`): root/via ids from `artifact_sources` joined to active `provenance = 'merged'` artifacts with `created_at > now - min_age_secs`. Called once per run, result used as a `HashSet` filter.

- Produces: `async fn rescue_one(core: &Core, c: &Chunk, reason: &str) -> Result<String>` returning the new artifact id:

1. **Prompt material.** Source-text candidate (`c.provenance.is_source_text()`): the candidate's own text. Model-written candidate: the texts of its root chunks (`root_chunks_of`), *never* its own text — the `is_model_written` rule. If a model-written candidate has no surviving roots with text (roots themselves reaped), skip the rescue with a warning; it stays a candidate.
2. **Call** `core.judge` (same completer, same gate protocol as Task 5) with `RESCUE_SYSTEM`; parse; on error warn-and-skip.
3. **Write** via `insert_synthesized_artifact(&new, &[c.id.clone()])` — sources list is the candidate; `roots_of` resolves through it. `cues: vec![format!("reaped rescue: {reason}")]`.
4. **Enqueue** `Stage::Embed` for the new id (as `src/jobs/pursuit.rs:175` does).
5. **Re-point the candidate**, under `lifecycle_lock`. Already-superseded candidate: leave its pointer alone; the rewrite still wins next cycle as a live neighbour.

Cap: `run` performs at most `max_rescues_per_run` rescues; further `Valuable` verdicts this run are logged and left as candidates.
